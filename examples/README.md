# Ark SDK examples

Runnable illustrations, deliberately kept outside `packages/` so nothing here
ships in a published SDK.

- `browser-upload/` — a React component doing direct uploads with `@ark/client`,
  plus the backend route that mints its short-lived session.
- `backend-usage/` — Node/Bun usage of both `Ark` (REST) and `ArkS3` (S3).
